\chapter*{{\khmoul អត្ថបទសង្ខេប}}
\addcontentsline{toc}{chapter}{{\khmoul អត្ថបទសង្ខេប}}

\begin{khmer}
\setstretch{1.5}

\hs ការត្រួតពិនិត្យហេដ្ឋារចនាសម្ព័ន្ធសំខាន់ៗ ដូចជា ស្ពាន អគារ និងផ្លូវរត់យន្តហោះ មានសារៈសំខាន់ណាស់សម្រាប់សុវត្ថិភាពសាធារណៈ។ ទោះជាយ៉ាងណា វិធីសាស្ត្រត្រួតពិនិត្យដោយដៃនាពេលបច្ចុប្បន្នមានចំណាយខ្ពស់ ពឹងផ្អែកលើការវាយតម្លៃផ្ទាល់ខ្លួន និងមានដែនកំណត់ក្នុងការគ្របដណ្តប់។ ទោះបីជាបច្ចេកវិទ្យា Deep Learning ទទួលបានជោគជ័យក្នុងការស្វែងរកស្នាមប្រេះលើរូបភាពថតជិតក៏ដោយ ការអនុវត្តលើរូបភាពអាកាសចរណ៍កម្រិតច្បាស់ខ្ពស់ដែលថតដោយដ្រូន (UAV) ប្រឈមនឹងបញ្ហាប្រឈមធ្ងន់ធ្ងរ៖ ស្នាមប្រេះដែលមានទទឹងត្រឹម ១-៣ ភិចសែល ត្រូវបង្ហាញលើរូបភាពទំហំជាង ១០ មេហ្គាភិចសែល ដែលគ្របដណ្តប់ផ្ទៃតិចជាង ០.០១\% នៃរូបភាពសរុប។ ទំហំដ៏ធំនេះលើសពីសមត្ថភាពអង្គចងចាំរបស់ GPU ស្តង់ដារ និងធ្វើឱ្យគំរូដែលមានស្រាប់បាត់បង់ព័ត៌មានលម្អិត ឬបរិបទរួម។

\hs គម្រោងសិក្សាស្រាវជ្រាវអនុវត្តការងាររយៈពេល ៣ ខែនៅក្រុមហ៊ុន AI Farm Robotics Co., Ltd. បានអភិវឌ្ឍ និងផ្ទៀងផ្ទាត់ប្រព័ន្ធ Deep Learning សម្រាប់កំណត់ទីតាំង និងបែងចែកស្នាមប្រេះកម្រិតភិចសែលដោយស្វ័យប្រវត្តិលើរូបភាពអាកាសចរណ៍ទំហំធំ។ ការស្រាវជ្រាវបានប្រៀបធៀបទម្រង់ស្ថាបត្យកម្មចំនួនបី៖ U-Net (ប្រើ EfficientNet-B0 encoder និង scSE attention), SegFormer (ប្រើ MiT-B0 encoder) និង YOLO26s-seg។ U-Net និង SegFormer បានប្រើប្រាស់អនុគមន៍ខាតបង់រួម (BCE + Dice + Focal Loss) ដើម្បីដោះស្រាយបញ្ហាភាពមិនសមតុល្យខ្លាំងរវាងថ្នាក់ទិន្នន័យ (Class Imbalance) ខណៈដែល YOLO26s-seg ត្រូវបានប្រើជាគំរូមូលដ្ឋានសម្រាប់ល្បឿន និងការដាក់ឱ្យប្រើប្រាស់។ លើសពីនេះ ប្រព័ន្ធដំណើរការរូបភាពតាមបំណែក (Tile-based inference) ដែលមានការជាន់គ្នា ២៥\% ត្រូវបានរចនាឡើងដើម្បីអាចដំណើរការរូបភាពទំហំធំបានដោយមិនកម្រិតលើ GPU តែមួយ។

\hs តាមរយៈការបណ្តុះបណ្តាលលើរូបភាពស្នាមប្រេះសាធារណៈសរុបចំនួន ៨,៨១៨ រូបភាព (បែងចែក ៨០\% បណ្តុះបណ្តាល, ១០\% ផ្ទៀងផ្ទាត់, ១០\% សាកល្បង) U-Net ទទួលបានកម្រិតភាពត្រឹមត្រូវខ្ពស់បំផុតលើសំណុំទិន្នន័យសាកល្បងសាធារណៈ (IoU ៥៣.០៤\%, F1 ៦៧.៥៩\%)។ ផ្ទុយទៅវិញ YOLO26s-seg មានល្បឿនលឿនជាងគេ (១៨.០៧ ms) ប៉ុន្តែទទួលបានភាពត្រឹមត្រូវទាបជាង (IoU ២៨.១០\%)។ ក្នុងការវាយតម្លៃលើទិន្នន័យ UAV ថ្មី (CUBIT-InSeg) ដោយមិនបានហ្វឹកហាត់ជាមុន (Zero-shot) លទ្ធផលផ្ទុយពីការរំពឹងទុកបានកើតឡើង៖ U-Net និង SegFormer បានធ្លាក់ចុះប្រសិទ្ធភាព (IoU ៥៣.០៤\% $\rightarrow$ ៣៩.៦២\% និង ៥១.២១\% $\rightarrow$ ៣៩.៤៦\% រៀងគ្នា) ខណៈដែល YOLO26s-seg បានកើនឡើងពី IoU ២៨.១០\% ទៅ ៤០.១២\% ដោយនាំមុខគំរូទាំងអស់បន្តិចលើសំណុំទិន្នន័យថ្មីនេះ។ បច្ចេកទេសបែងចែករូបភាពតាមបំណែកបានជួយរក្សាភាពជាប់គ្នានៃស្នាមប្រេះឆ្លងកាត់ព្រំដែនបំណែករូបភាពបានយ៉ាងល្អ។ លទ្ធផលទាំងនេះបញ្ជាក់ថាគ្មានស្ថាបត្យកម្មណាមួយដែលល្អដាច់គេលើគ្រប់លក្ខខណ្ឌនោះទេ ហើយការស្រាវជ្រាវនេះបានផ្តល់គ្រឹះយ៉ាងសំខាន់សម្រាប់ការកែសម្រួលនៅពេលដាក់ឱ្យប្រើប្រាស់ (Deployment-time fine-tuning) និងការប្រើប្រាស់លើឧបករណ៍ Edge Device ក្នុងការត្រួតពិនិត្យហេដ្ឋារចនាសម្ព័ន្ធជាក់ស្តែង។ 

\vspace{0.5cm}
\noindent\textbf{ពាក្យគន្លឹះ:} crack segmentation, រូបភាព UAV, Deep Learning, U-Net, SegFormer, YOLO,  tile-based inference, ភាពមិនសមតុល្យនៃចំណែកថ្នាក់, ការត្រួតពិនិត្យហេដ្ឋារចនាសម្ព័ន្ធ
